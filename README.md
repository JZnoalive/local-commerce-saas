# EvoNuevo — Plataforma de Comercio Local y Domicilios

Desarrollado por **JZnoalive** (`github.com/JZnoalive`).

Aplicación web full-stack para digitalizar comercios locales, centralizar catálogos de productos y gestionar pedidos directos hacia WhatsApp.

## Stack y arquitectura
- **Frontend:** Next.js (App Router), TypeScript estricto y Tailwind CSS.
- **Backend y Datos:** Supabase (PostgreSQL, autenticación y almacenamiento).
- **Calidad y Flujo IA:** Validación de contratos tipados en TypeScript y flujo de desarrollo modular asistido por IA.

## Despliegue
Publicado en producción mediante Vercel con integración continua desde GitHub.
